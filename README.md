## 🚀 Panduan Menjalankan Proyek Secara Lokal

### 1. Clone Repositori
```bash
git clone https://github.com/iwanbops666/CV_AZID.git
cd CV_AZID
```

### 2. Instalasi Dependensi PHP & Node.js
```bash
composer install
npm install
```

### 3. Konfigurasi Environment
```bash
cp .env.example .env
php artisan key:generate
```

### 4. Jalankan Aplikasi
Jalankan development server Laravel dan build Vite:
```bash
# Terminal 1: Vite dev server
npm run dev

# Terminal 2: Laravel server
php artisan serve
```

Akses web melalui browser di: `http://127.0.0.1:8000` atau konfigurasi virtual host lokal (Laragon/XAMPP).
